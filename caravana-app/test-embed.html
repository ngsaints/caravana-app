🗺️ Mapa das Entidades Culturais do Espírito Santo

Este é um exemplo de como o mapa pode ser incorporado em qualquer site usando um iframe. O embed funciona em WordPress, Wix, Squarespace, ou qualquer plataforma que permita HTML personalizado.

📋 Como usar:
1. Copie o código do iframe acima
2. Cole no HTML do seu site (WordPress, Wix, etc.)
3. Ajuste a altura (height) conforme necessário
4. Pronto! O mapa estará funcionando no seu site
